📵 Why are notifications blocked?

System (Android-style) notification banners need the browser's permission — and browsers refuse to grant that permission to a page opened straight from Downloads or a file viewer (you'll see a URL like content://...). This isn't something the app can override.

The in-app reminders (toast + vibration) still work fine either way — that part doesn't need permission. If you want real system banners too, try opening this exact file directly through Chrome's address bar (not Downloads/Brave), or ask to have it hosted at a real web link instead of a local file.
